
This is the quarto project that is running live at http://explore.stemcoding.org

http://explore.stemcoding.org includes the STEMcoding activity explorer which is a way to navigate all the activities that are described on the [STEMcoding youtube channel](http://youtube.com/STEMcoding)

Our goal is to help science and math teachers to modernize their curricula with computer science and data science (for example spreadsheet) skills
